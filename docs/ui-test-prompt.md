Вставь содержимое блока ниже в чат с Claude в Chrome-плагине (или Claude.ai
с подключенным Chrome connector). Замени `{{SITE_URL}}` на реальный

## Промт (копировать всё что между линиями)

---

Ты QA-тестировщик. Прогони fcpolotsk.by (URL: `{{SITE_URL}}`) через визуальные
проверки на нескольких разрешениях и собери отчёт по найденным багам.

### Что делать

Для каждого из 8 viewport'ов открой сайт и обойди указанные страницы.

**Viewports:**
| Имя | Ширина × Высота | Тип |
|---|---|---|
| iPhone SE | 375 × 667 | Узкий мобайл |
| iPhone 16 | 393 × 852 | Современный iOS |
| Pixel 8 | 412 × 915 | Android типовой |
| iPad Mini portrait | 768 × 1024 | Узкий планшет |
| iPad Pro portrait | 1024 × 1366 | Большой планшет |
| Laptop | 1280 × 800 | Минимальный десктоп |
| Desktop | 1440 × 900 | Стандартный десктоп |
| Wide | 1920 × 1080 | FullHD |

**Страницы для каждого viewport'а:**
1. `/` — главная (Hero + MatchCenter + News + Team + Social + Results)
2. `/news` — индекс новостей
3. Любая `/news/[slug]` — открой первую карточку с главной
4. `/match-admin/login` — экран логина админки

### Для каждого экрана: чеклист проверок

Делай скриншот всей страницы (или хотя бы каждой видимой секции). Проверь:

**Горизонтальный скролл:**
- Нет ли горизонтального скролла на странице? (контент не должен выходить за viewport)
- Если есть — назови секцию которая виновата.

**Текст и типографика:**
- Нет ли обрезанного текста (труcate без необходимости)?
- Не перекрывают ли длинные строки соседние элементы?
- Не слишком ли крупный/мелкий шрифт для viewport'а?
- На мобиле — основной текст ≥14px, заголовки разборчивы?

**Layout:**
- Все секции одна под другой? Ничего не наезжает?
- Сетки (карточки новостей, состав команды) перестраиваются адекватно?
- На <md одна колонка, на md две, на lg три — везде ли это работает?

**Кнопки и интерактив:**
- Размер кнопок ≥44px по высоте для тачa?
- Tap-targets не слипаются (между ними ≥8px)?
- При :focus есть видимое выделение?

**Изображения:**
- Логотипы и фото игроков не растянуты/сжаты?
- Не выходят за пределы своих карточек?

**Sticky / fixed elements:**
- Header остаётся читаемым на разных страницах (solid на /news, transparent поверх Hero на /)?
- Sticky-элементы (sticky score на match-admin) не залипают и не перекрывают контент?

**Цвета и контраст:**
- Текст читаем на своём фоне (на тёмных секциях достаточно белый? на белых тёмный?)?

### Конкретные секции которые часто ломаются

1. **Hero на главной** — большой текст «БЕЛОЭРА» / «БЕЛОСИНИЙ», бейдж сезона, glass-карточка следующего матча
2. **MatchCenter «Игры сезона»** — пост-матч карточка с длинным турниром, синяя карточка следующего матча, таблица матчей справа
3. **«Наша команда»** — пилюли-фильтры (Все, Вратари…), сетка карточек игроков
4. **News index `/news`** — сетка карточек 3-2-1 (lg/md/sm)
5. **Header navigation** — на мобиле меню в гамбургер, на десктопе пилюли

### Формат отчёта

После обхода выдай:

**Сводка:**
- Всего viewport'ов проверено: X
- Всего страниц: Y
- Найдено багов: Z

**Баги** (по серьёзности):
- 🔴 Critical — горизонтальный скролл, накрытый контент, нечитаемый текст
- 🟡 Medium — некрасиво, но не сломано
- ⚪ Minor — мелочи

Для каждого бага:
- Viewport (например iPhone 16)
- Страница (`/news`)
- Секция (Hero / MatchCenter / Footer / …)
- Описание (1-2 предложения)
- Если возможно — скриншот

**Рекомендации** (1-3 пункта приоритета).

### Что не нужно делать

- Не тестируй авторизованную часть `/match-admin/*` после логина — там
  нужен пароль и реальные данные. Только login-страницу.
- Не пробуй заполнять формы — это смок-тест UI, не функциональный.
- Не пиши код фиксов — только репортишь баги, я починю сам.

Поехали — начинай с iPhone 16 на главной странице.
