# Тестирование сайта ФК Полоцк на мобиле

Гайд для коллеги, который будет проверять, не разваливается ли вёрстка
на телефоне. У тебя Android, а главный целевой девайс — iPhone 16
(так попросил владелец). К сожалению, нативный iOS-эмулятор работает
только на macOS, поэтому используем браузерные инструменты.

---

## Что и зачем

Сайт **fcpolotsk.by** — это лендинг футбольного клуба. Болельщики
заходят с разных устройств, чаще всего с телефона. Если на мобиле
что-то «уезжает», обрезается, накладывается одно на другое — это
баг, который нужно зафиксировать и сообщить.

Что обычно ломается:
- Длинные слова не помещаются и съезжают за край экрана
- Кнопки наезжают на текст
- Большие заголовки переносятся криво
- Картинки выпадают из карточек

## Главный инструмент: Chrome DevTools (бесплатно, точно)

### Шаг 1 — Установи Chrome

Если у тебя его нет: https://www.google.com/chrome/. Можно использовать
Edge / Firefox / Brave / Yandex — у них **очень похожие** DevTools, но в
гайде описан Chrome.

### Шаг 2 — Открой сайт

Зайди на тренировочный URL (его пришлёт владелец, обычно вида
`https://что-то-что-то.trycloudflare.com`) или на прод `https://fcpolotsk.by`.

### Шаг 3 — Включи DevTools

Три способа открыть:
- **F12**
- **Ctrl + Shift + I**
- Правый клик в любом месте страницы → **«Просмотреть код»** / «Inspect»

Справа (или снизу) откроется панель с кучей вкладок и кодом — это
DevTools.

### Шаг 4 — Переключись в режим устройства

В левом верхнем углу DevTools есть иконка **«📱 / 🖥»** (телефон+планшет).
Кликни её.

Или жми **Ctrl + Shift + M**.

Страница сразу сожмётся под мобильное окно. Над страницей появится
панелька с настройками устройства.

### Шаг 5 — Выбери iPhone 16

В верхней панели где написано «Dimensions: Responsive» или название
устройства — кликни на дроп-даун и выбери:

- **«iPhone 16 Pro»** — если есть в списке
- Иначе **«iPhone 14 Pro»** / **«iPhone 12 Pro»** — близкие по размеру
- Если совсем нет нужного — выбери «Responsive» и руками вбей в соседние
  поля **393 × 852** (это размер iPhone 16 в CSS-пикселях)

### Шаг 6 — Поверни если нужно

Кнопка с иконкой поворота (рядом с разрешением) — переключает портрет
↔ ландшафт. Обычно тестим в портрете.

### Шаг 7 — Тапы вместо кликов

В режиме устройства мышь работает как палец — клики = тапы. Свайпы делать
зажав левую кнопку и потянув.

### Шаг 8 — User-Agent

Это важно для редких багов. В правом верхнем углу панели устройств жми
**три точки → «Show device frame»** для красивой рамки iPhone. Также там
есть **«User-Agent»** — там по умолчанию идёт мобильный Safari, не трогай.

## Что проверять — чек-лист

Иди по этому списку. Если хоть один пункт **не** соответствует ожиданиям —
сделай скрин и пришли в чат с пояснением.

### Главная страница `/`

#### Hero (верхний блок)
- [ ] Логотип ФК Полоцк в шапке слева
- [ ] Гамбургер-меню (☰) справа в шапке (на мобиле меню сворачивается)
- [ ] Тап на гамбургер → открывается боковое меню с пунктами «Главная», «Матчи», «Новости», «Команда», «Соцсети», «Результаты»
- [ ] Бейдж «Сезон 2026 · Вторая лига» сверху, не наезжает на меню
- [ ] Большая надпись «БЕЛО» / «СИНИЙ» в 2 строки. Должна быть крупная, но **не вылазить за края экрана**
- [ ] Подзаголовок «ФК Полоцк — клуб...» влезает целиком
- [ ] Кнопки «Ближайший матч» и «Состав» — на одной или двух строках, тапаются нормально
- [ ] Карточка «Следующий матч» / «Сыгран ...» / «Расписание уточняется» — под кнопками. Не обрезана, отступы по краям одинаковые

#### Если есть live матч (когда тестируешь во время игры):
- [ ] Красный бейдж «🔴 LIVE · N′» виден сверху карточки
- [ ] Счёт `0:0` или текущий — большой и читаемый
- [ ] Логотипы команд по бокам от счёта
- [ ] Внизу карточки переключатель табов: «Лента / Составы / Статистика»
- [ ] Тап по табу — переключается, контент меняется

#### Матч-центр (секция «Игры сезона»)
- [ ] Заголовок «Игры сезона» с отступом слева от края экрана
- [ ] Карточка последнего сыгранного матча: дата сверху, бейдж «Победа/Ничья/Поражение» справа сверху, ниже турнир мелким шрифтом
- [ ] Команды + счёт по центру
- [ ] Голы и их авторы (если есть) — каждая строка целиком на одной линии
- [ ] **Имена не обрезаются**, не наезжают друг на друга
- [ ] Большая синяя карточка «Следующий матч» — логотипы, vs, дата/время/стадион, кнопки «Статистика сезона» и «В календарь»
- [ ] Кнопка «В календарь» — обводка чистая, без артефактов и двойных линий
- [ ] Под главной карточкой блок «Последние матчи» (список 2-4)
- [ ] Ещё ниже «Турнирная таблица» — строки помещаются, цифры не съезжают, ФК Полоцк подсвечен синим

#### Новости
- [ ] Заголовок «Последние события» + ссылка «Все новости →»
- [ ] Карточки новостей — 1 в строку на мобиле, фото с тегом сверху, дата + заголовок + краткий текст под фото
- [ ] Тап по карточке → переход на страницу новости

#### Наша команда
- [ ] Заголовок «Наша команда»
- [ ] Фильтр позиций сверху: Все / Вратари / Защитники / ... / Тренеры
- [ ] Карточки игроков — 2 в строку на мобиле
- [ ] Фото игрока + страна и позиция в правом верхнем углу + большая цифра номера сзади
- [ ] Имя игрока + номер крупно внизу карточки

#### Соцсети
- [ ] 3-4 цветных блока (Instagram / Telegram / VK)
- [ ] Тап → открывает соцсеть в новой вкладке

#### Результаты
- [ ] Таблица матчей за сезон с датой / турниром / счётом / итогом
- [ ] На мобиле строки превращаются в карточки — должны быть читаемые
- [ ] Внизу 4 плашки со статами: очки / победы / голы забито / голы пропущено

#### Footer
- [ ] Логотип ФК + название «ФК Полоцк» + «Football Club · Est. 2019»
- [ ] Колонки «Клуб» / «Матчи» / «Контакты»
- [ ] Соцсети-иконки (Instagram / Telegram / VK / YouTube)
- [ ] Все ссылки тапаются и не съезжают

### Страница новости `/news/[slug]`

Открой первую новость на главной → попадёшь сюда.

- [ ] Хедер сайта (логотип + меню) виден, **не прозрачный** — белый/тёмный фон
- [ ] Хлебные крошки сверху: «Главная > Новости > Заголовок»
- [ ] Тэг новости + дата + время чтения
- [ ] Большой заголовок статьи (Oswald)
- [ ] Лид-абзац с синим бордером слева
- [ ] Аватарка пресс-службы + кнопки «Поделиться»
- [ ] Основной текст статьи с нормальными отступами между абзацами
- [ ] Если есть фото внутри текста — оно во всю ширину карточки
- [ ] Sidebar справа (на мобиле — снизу): «Поделиться», «Другие новости», синяя клубная карточка

## Альтернатива — реальный iPhone через BrowserStack

DevTools показывает 95% багов, но иногда **только настоящий iPhone** покажет
проблему (например, отступы snap-scroll, рендер шрифта Safari, поведение
при свайпе). Если владелец просит «проверь на настоящем айфоне» — используй
**BrowserStack**.

### Регистрация (бесплатно 30 минут)

1. https://www.browserstack.com/users/sign_up
2. Завершить email-верификацию
3. Login → меню сверху → **Live**
4. Выбрать **Mobile** → **iPhone 16 / iPhone 15 / iPhone 14**
5. Браузер: Safari
6. Жми «Start session»
7. Откроется виртуальный iPhone в твоём окне Chrome. Управляй мышью как пальцем.
8. В адресной строке введи URL сайта или вставь ссылку от владельца.

Тестируй то же что в чек-листе выше. Если что-то ломается только на реальном
iPhone (а в DevTools было ок) — это особенно ценная находка.

**Бесплатный лимит — 30 минут.** Не транжирь, используй для финальной
проверки после правок, а не для свободного блуждания.

## Как сообщать о баге

**Что нужно в сообщении владельцу:**

1. **Где** — какая страница (URL) и какой блок («главная, секция Игры сезона»)
2. **Что не так** — словами, что ты видишь
3. **Что ожидал** — как должно быть, по твоему мнению
4. **Скриншот** — обязательно. На скрине стрелочкой или подписью пометь проблему
5. **Устройство** — «Chrome DevTools, iPhone 16 portrait» или «BrowserStack, real iPhone 16, Safari»

### Пример хорошего сообщения

> Главная страница, блок «Игры сезона», карточка пост-матч.
> Текст «Сыгран · 31 мая · Вторая лига - Витебский дивизион» залазит за
> бейдж «Ничья» — буквы «изион» обрезаны зелёной плашкой.
> Ожидал: длинный текст переносится на новую строку либо турнир уезжает
> отдельной строкой.
> Скрин: [приложен].
> Chrome DevTools, iPhone 16 portrait.

### Пример плохого сообщения

> Что-то странно отображается, посмотри.

Владелец будет неделю выяснять что у тебя странно.

## Часто задаваемые вопросы

**Q: А поворот экрана нужно тестить?**
A: Да, особенно если что-то узкое на портрете — посмотри в ландшафте,
может стало нормально.

**Q: Какие ещё телефоны кроме iPhone 16?**
A: Сейчас цель — iPhone 16. Дополнительно можешь быстро прогнать на iPhone
SE (375×667 — самый узкий из актуальных) и Galaxy S20 (412×915 —
среднестатистический Android). Если на этих трёх ок — на остальных тоже.

**Q: Я нашёл баг, но не знаю баг это или фича?**
A: Лучше сообщи. Если фича — владелец просто скажет «так и задумано».

**Q: Зум пальцами / pinch-to-zoom работает?**
A: Должен. Если нет — это баг (зум обычно нужен для доступности).
DevTools зум не очень эмулирует, лучше проверить в BrowserStack.

**Q: Что значит «свайп»?**
A: Удерживай левую кнопку мыши и тяни. В DevTools mobile mode это будет
работать как палец на сенсоре. На самом телефоне — палец и движение.

**Q: А что если сайт не открывается вообще?**
A: Сначала проверь обычный браузер на ПК — мб владелец выключил dev-сервер
или туннель. Напиши ему «не открывается, посмотри пожалуйста».

## Что делать дальше

1. Открой главную → пройди по чек-листу для главной
2. Открой страницу новости → пройди по чек-листу для статьи
3. Сделай скриншоты багов с пометками
4. Скинь владельцу в чат списком: «нашёл 5 багов, описания + скрины»

Удачи. Чем больше багов найдёшь сейчас — тем меньше потом проблем у
болельщиков.
